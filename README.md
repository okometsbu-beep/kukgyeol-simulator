# 진심의 증거 v17 · 국제연애 라이프 RPG

제한된 시간 안에 관계·생활·언어·진실을 함께 준비하고, 국제연애의 첫 만남부터 결혼·신혼·가족 생활까지 이어 가는 모바일 라이프 RPG입니다. 미스터리와 사실 확인은 핵심 전략 중 하나지만 게임 전체를 지배하지 않습니다.

## v17 핵심

- 중요 장면 사이에 7번의 `주간 계획` 턴을 넣었습니다. 매번 관계·생활·언어·통찰·회복 중 하나만 고를 수 있고 5~7일이 실제로 흐릅니다.
- 관계 2, 생활 1, 언어+통찰 합계 2를 준비해야 결혼 제안을 꺼낼 수 있습니다. 초반의 작은 성장 선택이 후반의 큰 선택을 직접 잠그거나 엽니다.
- 주간 계획은 호감만 올리는 버튼이 아닙니다. 추가 수입은 스트레스를, 독립 확인은 상대 피로를, 회복은 성장 기회 손실을 동반합니다.
- HUD에 관계·생활·언어·통찰 장기 트랙을 상시 표시해 이번 회차의 빌드와 부족한 준비를 즉시 읽을 수 있습니다.
- 언어 트랙은 전문 통역 비용을 레벨당 15%, 최대 45% 줄여 장기 성장과 실제 선택 비용을 연결합니다.
- 엔딩 기록은 별도의 회차 메타 진행으로 남습니다. 한 번 엔딩을 본 뒤에는 `지난 회차의 실패 기록 복기` 행동이 열려 이전 실패를 다음 판의 통찰 자원으로 바꿀 수 있습니다.
- 기존 관계 기억·파트너 전용 생활 사건·증거·협상·재정·주거·결혼 후 24개월 시스템은 이 새 반복 루프의 장기 결과층으로 유지합니다.

## v16 핵심

- 8개 파트너 성향마다 장소·갈등·욕망이 다른 전용 생활 사건이 등장합니다.
- 전용 사건의 세 선택은 주사위 없이 바로 반응하며, 결혼 뒤 일 장면에서 선택의 후유증이 다시 돌아옵니다.
- 같은 국가·같은 경로라도 파트너가 지키려는 삶에 따라 읽어야 할 단서와 다음 플레이가 달라집니다.

## v15 핵심

- 상대의 말풍선은 뜻이 확정된 한국어로 바로 읽힙니다. 국적별 범용 외국어 문장으로 실제 대사가 가려지지 않습니다.
- 선택 뒤에는 내 말, 상대의 즉시 반응, 내 후속 답변, 성향별 마지막 대답까지 이어져 한 번의 선택이 짧은 대화로 완결됩니다.
- 세 번 이상 대화하면 번역 버튼이 아니라 반복된 말투를 근거로 상대의 MBTI가 프로필에 열립니다.

## v14 기반 시스템

- 초반의 약속·과장·선물·가족 돈·동의가 `관계가 기억한 말`로 남고, 관련 후반 장면에서 인물별 말투로 다시 인용됩니다.
- 같은 기억도 후반 행동에 따라 `지킨 약속`, `깨진 약속`, `아직 판단 중`으로 갈리며 신뢰·호감·갈등·상대 피로를 실제로 바꿉니다.
- 내 프로필에서 아직 회수되지 않은 말과 후유증이 돌아온 기록을 확인할 수 있습니다.

## v13 핵심

- 결혼 뒤 월수지가 무너지면 화면에 적자·급전 경보가 뜨고, 생활비·개인비·가족지원·왕래비를 다시 합의하는 `가계 구조조정` 선택이 열립니다.
- 흑자 현금은 비상금을 제외하고 급전을 자동 상환합니다. 재정과 갈등이 안정된 달에는 스트레스도 회복되어 후반 가족 서사까지 도달할 수 있습니다.

## v12 기반 시스템

- 타이틀에서 `오늘의 사건 바로 시작`을 누르면 균형형 주인공, 국가, 만남 경로, 기본 이용 방식이 자동 배정되고 후보 3명 선택부터 시작합니다. 기존 5단계 설정은 `직접 설정하고 시작`으로 유지됩니다.
- 사람의 성격과 대화 맥락으로 결정되는 선택은 `상대 읽기`, 실제 무작위 사건만 `세계 변수`로 표시해 주사위처럼 오해되는 신호를 분리했습니다.

## v11 기반 시스템

- 일반 대화에서 성공 확률과 주사위를 제거했습니다. 여성의 MBTI, 숨은 반응 성향, 현재 감정, 이전 행동과 소통 맥락이 선택 결과를 결정합니다.
- 주사위는 임신, 사업 결과처럼 플레이어가 통제할 수 없는 `세계 변수`에만 남습니다.
- 중요한 협상에서는 전문 통역을 켜 비용을 지불하고 소통 정확도를 높일 수 있습니다. 화면의 서사 대사는 한국어로 바로 표시됩니다.
- 프로필·대화·원본 자료 세 쌍 중 실제 모순을 직접 고르는 `모순 연결 보드`를 추가했습니다.
- 거주, 경력, 가족 지원, 돈 관리 네 항목을 한 번에 조율하는 `결혼조건 협상판`을 추가했습니다. 결과는 안정 합의, 비싼 타협, 원한이 남은 절충, 결혼 유예로 갈립니다.
- 남성에게 여러 욕구 목록 대신 강박 하나를 부여했습니다. 강박에 맞는 선택은 즉시 보상을 크게 주지만 반복하면 스트레스·갈등·상대 피로가 후유증으로 돌아옵니다.
- 62세 황혼 직진남, 55세 고깃집 사장, 28세 라이더를 추가해 남성 주인공을 9명으로 확장했습니다.
- 관계 파탄, 시간 초과, 결혼 거절, 잘못된 지목 뒤에는 취소·정리 비용, 21일, 스트레스를 잃은 상태로 새 후보 3명 중 다시 시작할 수 있습니다.
- 실제 만남 전에는 프로필 사진을 확대해도 필터 사진만 유지됩니다. 새 정보가 열리면 상대 프로필에 `NEW`가 표시됩니다.
- 모바일 장면 이미지를 16:9 전체 프레임으로 통일하고, 대화를 여성의 흰 말풍선과 내 노란 말풍선으로 정리했습니다.
- 국가별 왕복 항공, 4박 숙소, 기본·고급 데이트 대표 비용을 선택 화면에 표시하며 현지 첫 만남에서 같은 금액을 실제 차감합니다.

## 이어지는 장기 시스템

- 6개 국가, 국가별 얼굴 8명과 생성형 이름·직업·도시·관심사 조합
- 앱, 지인 소개, 국제결혼 업체, 국제교류 모임의 서로 다른 후보·결제·사건 구조
- 진심, 현실적 결혼, 번역 오해, 업체 가로채기, 숨은 혼인, 체류 계획, 공모 사기 등 10개 숨은 사건
- 호감, 그녀의 신뢰, 사실 확인도, 갈등, 상대 피로를 별도 수치로 관리

- 결혼 뒤 예식, 주거, 생활비, 배우자 취업, 가족 송금, 친밀감, 임신·출산·육아, 부부 갈등까지 24개월 진행

- 수입 변동, 생활비, 주거비, 급전 이자와 6개월 가계 전망
- 기기 내 자동 저장과 PWA 홈 화면 설치

## 비용 모델

모든 금액은 실제 결제가 아닌 게임 속 지출입니다. 업체 노선, 결혼식, 양육비, 서울 주거와 대출 조건은 공개된 대표 수치를 단순화했고, 국가별 항공·숙박·데이트 비용은 2026년 여행 가격과 생활비 수준을 바탕으로 만든 게임상 대표값입니다. 실제 시세·대출 가능액·개인 상황과는 다를 수 있습니다.

## 실행

별도 빌드가 없는 정적 웹앱입니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 여세요. HTTPS로 배포하면 iPhone Safari의 공유 메뉴에서 홈 화면에 추가할 수 있습니다.

## 파일 구조

- `index.html`: 화면 구조와 접근성 마크업
- `styles.css`: 모바일 비주얼노벨, 채팅, 미니게임 UI
- `game-data.js`: 인물, 행동 성향, 강박, 국가별 여행비, 숨은 사건 데이터
- `game.js`: 결정형 대화, 인물별 후속 문답, 모순 연결, 협상, 재매칭, 재정·주거·결혼 엔진
- `service-worker.js`: v17 오프라인 캐시
- `assets/`: 가상 성인 인물과 컷신 이미지

## 주의

모든 인물과 사건은 허구입니다. 국적, 직업, 외모, 문신, 야간근무, 가족 지원이나 임신 의향은 범죄의 증거가 아닙니다. 이 게임은 실제 사람의 진심이나 범죄 가능성을 예측하는 도구가 아닙니다.
