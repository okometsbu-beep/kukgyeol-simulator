# 진실의 번역 v18 · 관계 추리 어드벤처

국제결혼을 결정하기 전, 서로에게 전달된 말과 실제 원문이 같은지 조사하는 정적 웹 어드벤처입니다. v17까지의 라이프 RPG·주간 계획·재정·결혼 후 시뮬레이션 구조는 사용하지 않습니다.

## v18 게임 문법

1. **자유 조사** — 장소의 오브젝트를 살피고 인물에게 주제를 골라 질문합니다.
2. **검증 파일** — 원문, 업체 문서, 대화 내보내기, 생활 자료, 시스템 로그를 출처와 함께 모읍니다.
3. **문장별 교차검증** — 진술을 앞뒤로 넘기고 `더 묻기`로 맥락을 확인합니다.
4. **기록 대조** — 특정 진술에 특정 기록을 제시해 의미가 어긋나는 지점을 증명합니다. 틀린 지적은 신뢰를 잃습니다.
5. **흐름 복원** — 마지막에는 사건을 설명하는 핵심 기록을 시간순으로 연결합니다.
6. **결정** — 진실을 찾는 것과 결혼을 선택하는 것은 별개입니다. 사실 확인 뒤 관계의 결론을 플레이어가 정합니다.

## Episode 01 — 같은 말, 다른 뜻

도윤은 결혼 계약 9일 전, 린이 자신과 전혀 다른 내용으로 생활 조건을 이해하고 있음을 발견합니다. 플레이어는 누군가를 먼저 범인으로 정하지 않고 한국어 프로필, 원문 상담서, 릴레이 채팅, 통화 메모와 수정 로그를 대조해야 합니다.

핵심 반전은 특정 국적이나 가족 지원 자체를 위험 신호로 취급하지 않습니다. 정보가 번역·요약·중개되는 과정에서 **누가 어떤 의미를 지웠는지**가 사건의 중심입니다.

## 실행

별도 빌드가 없는 정적 웹앱입니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 파일 구조

- `index.html` — 타이틀, 조사, 교차검증, 복원, 엔딩 화면
- `styles.css` — PC/모바일 반응형 비주얼노벨 UI와 조사/진술 연출
- `game-data.js` — 1화 전체 대사, 증거, 조사 행동, 진술, 엔딩 데이터
- `game.js` — 조사, 증거 수집, 교차검증, 신뢰 페널티, 복원, 저장 엔진
- `service-worker.js` — v18 오프라인 캐시
- `assets/reboot/` — v18 전용 신규 배경·인물 리소스

모든 등장인물과 사건은 허구입니다. 국적, 가족 지원, 직업 또는 결혼 이력 그 자체는 사기나 위험의 증거로 취급하지 않습니다.
